# HAGISILTA

[English](README.md) | 한국어

DeepLabCut 기반 행동실험 트래킹, 모델 개발 플랫폼입니다.

HAGISILTA는 아래 영문 표현의 약자이며, 사람이 참여하는 검수, 라벨링, 추적, 분석
작업을 체계적으로 지원한다는 의미를 담았습니다.

Human-Assisted Graphical Interface for
Systematic Inspection, Labeling, Tracking, and Analysis.

| H | A | G | I | S | I | L | T | A |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Human | Assisted | Graphical | Interface | Systematic | Inspection | Labeling | Tracking | Analysis |

## 주요 기능

- DeepLabCut으로 영상 프레임에 라벨을 만들고, 자세 모델을 학습, 평가하며 신체점을 추적합니다.
- 추론 결과를 검수하고 좌표를 교정하며 후처리 설정을 비교합니다.
- Novel Object Recognition Test(NORT), Y-maze, Water maze와 일반 구역 실험을 분석합니다.
- ROI와 분석 구간을 지정하고 여러 영상을 검수하며 프로젝트를 내보냅니다.
- 프로그램, 편집 창과 설치기를 한국어 또는 영어로 사용합니다.

## 배포 및 실행 환경

HAGISILTA는 Windows 데스크톱 프로그램입니다. 전용 Miniforge/Python 환경에서
GUI, 학습과 추론을 실행합니다. 앱 ZIP에는 소스, 설치와 실행 도구, 현재 사용하는
리소스와 번역 파일이 포함됩니다.

## 새 컴퓨터에서 처음 설치

1. `HAGISILTA-app.zip`의 압축을 완전히 풉니다.
2. 인터넷 연결을 확인하고, NVIDIA GPU를 사용할 경우 그래픽 드라이버도 확인합니다.
3. `HAGISILTA-Setup.cmd`를 더블클릭합니다.
4. 설치가 끝나면 HAGISILTA가 자동 실행됩니다.
5. 이후에는 바탕화면의 `HAGISILTA` 바로가기를 사용합니다.

설치, 복구, 관리 메뉴의 안내는 저장된 화면 언어를 따릅니다. 저장되거나 전달된
언어가 없으면 대화형 설치기에서 한국어 또는 영어를 선택합니다.
`HAGISILTA-Setup.cmd -Language en` 또는 `-Language ko`로 지정할 수도 있으며,
복구, 관리 메뉴 실행 파일도 같은 옵션을 받습니다. 명시적으로 선택한 언어는
Python 환경이 준비되면 저장되고 환경 검사와 앱 실행에도 전달됩니다.
일반 앱 실행에서는 언어 선택 창을 띄우지 않습니다. 외부 설치 도구의 출력 언어는
해당 도구가 제공하는 원문을 유지합니다.

설치기는 HAGISILTA 전용 Miniforge, 전용 Python 3.12 환경, DeepLabCut 3.0.0,
HAGISILTA 라벨링 도구, PyTorch와 기타 필수 패키지를 자동으로 준비합니다. NVIDIA GPU가 감지되지
않으면 CPU 버전을 설치하지만 학습과 추론 속도는 매우 느릴 수 있습니다.

전용 환경은 `%LOCALAPPDATA%\HAGISILTA\miniforge3` 아래에 설치됩니다.
PC에 이미 설치된 Python, Anaconda, Miniconda 또는 다른 Conda 환경은 검색하거나
변경하지 않습니다. 환경 이름은 `hagisilta-dlc-3.0`이며 다른 연구용 Python 환경과 별도로 관리합니다.

설치에는 인터넷 연결이 필요하며 설치 드라이브에 최소 12GB, 원활한 프로젝트
작업을 위해 20GB 이상의 여유 공간을 권장합니다. 별도의 CUDA Toolkit 설치는
필요하지 않지만 GPU를 사용하려면 NVIDIA 그래픽 드라이버를 미리 설치해야 합니다.

## 실행과 복구

- `HAGISILTA-Run.cmd`: 설치된 HAGISILTA 실행
- `HAGISILTA-Repair.cmd`: 패키지 누락이나 업데이트 문제 복구
- `HAGISILTA-Menu.cmd`: 실행, 설치, 복구, 환경 점검 메뉴

설치 로그는 `%LOCALAPPDATA%\HAGISILTA\logs`에 저장됩니다.

직접 CLI를 실행할 경우 Y-maze는 `hagisilta_ymaze_analysis.py single ...` 또는
`hagisilta_ymaze_analysis.py batch ...`를 사용합니다. 좌표 보정은
`hagisilta_pose_postprocess.py filter ...`, 저장한 분석 입력 일괄 적용은
`hagisilta_pose_postprocess.py apply ...`입니다. 각 모드 뒤에 `--help`를 붙이면
사용 가능한 인자를 확인할 수 있습니다.

## 화면 언어

메인 창 상단의 `Language`에서 `한국어` 또는 `English`를 선택한 뒤 다시 실행하면
프로그램과 편집, 검수 창 전체에 적용됩니다. 선택은 이 컴퓨터에 저장됩니다.
선택기를 바꿔도 현재 창과 진행 중인 작업은 기존 언어로 계속 열려 있습니다.
번역은 인터넷 없이 동작하며 프로젝트명, 파일명, 사용자 입력과 분석 데이터는
저장된 값을 유지합니다.

영문 화면의 `Fine-tuning`은 기존 가중치에서 시작하는 모델 보강학습,
`Postprocessing`은 좌표 후처리를 뜻합니다. 이름 없는 구역의 기본 이름,
QC 경고와 저장된 교정 시작 좌표의 출처 라벨은 일관된 영문 값을 사용합니다.
교정 창에서는 출처 설명을 선택한 화면 언어로 표시합니다.

## 모델 작업 흐름

1. `SuperAnimal 모델 확인`에서 대표 영상과 ROI로 촬영 조건에 맞는 신체점 검출이 되는지 확인합니다.
2. 결과가 적합하면 `영상 트래킹`에서 전체 영상을 처리합니다. 부족하면 `데이터셋 관리`에서
   라벨을 만들고 모델을 학습한 뒤 `모델 평가`에서 성능을 확인합니다.
3. 트래킹 결과를 검수하고 필요에 따라 좌표 교정이나 후처리를 적용한 뒤 행동 분석에 사용할 좌표를 지정합니다.
4. 실험 구역과 분석 구간을 설정하고 분석을 실행합니다. 입력이나 설정을 바꾼 뒤에는 다시 분석하여 결과를 갱신합니다.

## 영상 재생과 확인 영상

영상 교정, 추론 확인, 프레임 라벨링, 후처리 비교와 NORT, Y-maze, Water maze의
분석 구간 및 판정 검수 창에서 `재생 배속`을 선택할 수 있습니다. 기본은 1×이며
0.25×, 0.5×, 1×, 1.5×, 2×, 4×를 제공합니다. `Ctrl+[`로 느리게,
`Ctrl+]`로 빠르게 재생합니다.

배속 변경은 즉시 적용되고 영상이나 ROI를 전환해도 유지됩니다. 1프레임,
1초 이동량은 배속과 관계없이 같습니다. 배속은 화면 재생에만 영향을 줍니다.
프레임을 생략하지 않으므로 처리량이 많은 영상에서는 선택한 배속보다 느릴 수 있습니다.

모델 평가, 영상 트래킹과 SuperAnimal 모델 확인에서 신체점, 연결선, 검출 박스를
표시한 확인 영상은 FFV1 무손실 AVI로 저장합니다. MP4보다 용량이 커질 수 있습니다.
저장한 모든 프레임을 검사하고 검증 정보를 `.lossless.json`에 기록합니다.
홀수 크기에는 오른쪽이나 아래에 최대 1px의 여백을 추가합니다. 확인 영상을
다시 만들면 기존 MP4는 보존하고 ROI 영상과 좌표에서 AVI를 생성합니다.
무손실 저장은 인코딩할 이미지를 보존하며 원본에 이미 있는 손실을 복원하지는
않습니다. 행동 판정 영상은 별도의 출력 형식을 사용합니다.

## ROI 영상과 트래킹 진행

ROI 영상은 FFV1 무손실 압축으로 ROI의 크기, FPS, 프레임과 픽셀값을 유지합니다.
`영상 트래킹 → 세부 실행 설정`에서 `동시 ROI 준비 수`와 `ROI 저장 검사`를
각각 선택합니다. 동시 준비 수가 4이면 생성하거나 검사하는 ROI가 최대 4개이며,
GPU 추론을 동시에 4개 실행한다는 뜻은 아닙니다.

| 검사 방식 | 확인 내용 | 사용할 때 |
| --- | --- | --- |
| 빠른 검사, 일괄 트래킹 기본값 | 코덱, 크기, FPS, 기록된 프레임 수와 앞, 중간, 끝을 포함한 최대 9프레임의 픽셀 | 표본 픽셀 검사로 충분한 일반 실행 |
| 정밀 검사 | 영상 속성과 저장된 모든 프레임 | 전체 프레임 검증이 필요하거나 저장 오류가 의심될 때 |

두 방식은 같은 무손실 ROI 영상을 만듭니다. 빠른 검사는 표본에 포함되지 않은
프레임을 확인하지 않습니다. 신체점 확인 영상은 항상 전체 검증을 수행합니다.
새 ROI는 선택한 검사를 통과한 뒤 기존 파일을 교체합니다. 생성 또는 검증 오류가
발생하면 완성된 파일은 보존하며, 프로세스를 강제로 종료하면 미완성 임시 폴더가
남을 수 있습니다.

결과 표의 `상태` 열과 실행 로그에서 ROI 준비, 추론, 좌표 저장, 확인 영상 생성과
완료를 확인합니다. 원본 영상의 상태에 마우스를 올리면 ROI별 상태가 나옵니다.
`전체 완료`는 확인 영상을 비롯해 요청한 추론 후 작업까지 끝났다는 뜻입니다.
확인 영상 생성을 끄면 좌표 처리 후 완료됩니다. 큐 모드에서는 모든 추론이
끝난 뒤 확인 영상을 만듭니다.

진행과 완료 상태는 ROI 출력 폴더의 `tracking-status.json`에 저장됩니다.
`좌표 있음`은 좌표 파일이 있으나 완료된 실행이 검증되지 않았다는 뜻입니다.
중단, 오류와 미실행 ROI는 미완료로 남습니다.

확장자를 제외한 이름이 같은 영상은 ROI와 분석 출력 폴더가 겹칠 수 있습니다.
서로 다른 이름을 사용하거나 프로젝트로 복사할 때 자동 번호 붙이기를 선택하세요.
HAGISILTA는 연결 등록이나 일괄 실행 전에 충돌을 알리고 다른 원본에 속한 결과를 보존합니다.

## 학습 이미지 크기

`모델 학습 → 세부 학습 설정 → 학습 입력 영역`에서 다음 방식을 선택합니다.

- 전체 ROI 크기 자동 설정은 모든 Train 이미지와 회전, 배율 증강 범위로 입력 크기를
  계산하고 필요한 곳에 검은 여백을 추가합니다.
- `라벨 주변 크롭`은 전체 ROI를 축소하지 않고 지정한 가로, 세로 영역을 사용합니다.
  모든 라벨 신체점과 주변 32px를 보존하는 범위에서 크롭 위치를 바꿉니다.

크롭 가로와 세로는 각각 32 이상의 32배수여야 합니다. 최대 회전과 확대 조건에서
Train 라벨을 담을 수 없는 크기이면 학습을 막고 필요한 값을 안내합니다.
라벨이 없는 신체 부위는 크롭 밖으로 잘릴 수 있으므로 `입력 미리보기`에서 확인하고
충분한 여유를 두세요. 입력 면적을 줄이면 GPU 메모리를 줄이는 데 도움이 되며,
부족하면 Pose 배치도 줄일 수 있습니다. 크기 검사에는 메모리 재생에 쓰는 라벨도 포함합니다.

`입력 미리보기`는 왼쪽에 증강된 전체 이미지와 크롭 위치, 오른쪽에 학습 입력과
라벨 안내선을 표시합니다. 미리보기는 고정된 크롭 위치를 사용하고 학습에서는
위치가 바뀝니다. 파란 경계와 라벨 점은 안내 표시이며 실제 학습 이미지에는
포함되지 않습니다. 원본 이미지와 라벨은 보존합니다.

두 방식 모두 입력 크기에 맞추기 위한 축소는 하지 않으며 회전과 배율 변경은
증강에 포함됩니다. Validation, Test와 영상 추론은 수동 학습 크롭이나 정답 라벨을
따른 크롭 대신 원본 ROI를 사용하고 고정 위치에 여백을 추가해 크기를 32배수로 맞춥니다.

### 영상 평가의 입력 패딩

모델 평가의 영상 시험 및 QC 영역에서 `시험 영상 입력 패딩`을 현재 실행에 적용합니다.

| 선택 | 적용 내용 |
| --- | --- |
| `모델 기본` | 모델에 저장된 추론 설정 사용 |
| `최소 패딩` | 가운데 정렬한 검은 여백으로 가장 작은 32배수 크기에 맞춤 |
| `학습과 동일` | 모델에 기록된 전체 ROI 학습 크기 사용 |

모델의 학습 크기 기록이 없거나 ROI가 그보다 크면 `학습과 동일`을 사용할 수
없습니다. 크롭 또는 전체 이미지 축소로 학습한 모델도 이 옵션을 사용할 수 없습니다.
화면에 이유가 표시되며 `모델 기본`과 `최소 패딩`은 계속 사용할 수 있습니다.
각 실행의 ROI와 결과 파일은 별도로 저장하고 결과 표에 패딩 방식을 표시합니다.
이 선택은 영상 시험에 적용되며 정량 Validation/Test 평가나 저장된 모델을 바꾸지 않습니다.

학습 폴더의 `hagisilta-input-layout.json`에 Train 목록과 입력 설정을 기록합니다.
크롭의 효과를 확인하려면 기존 라벨로 새 Shuffle을 학습하고 원본 ROI 크기의
보류 영상에서 비교하세요. 크롭이 인식 정확도 향상을 보장하지는 않습니다.
같은 학습 절차를 재현하려면 HAGISILTA를 사용하세요. 저장된 가중치와 추론 설정은
DLC 추론에서도 사용할 수 있습니다.

## 좌표 후처리와 분석 입력

모델 평가의 `04 좌표 후처리 비교` 또는 영상 트래킹의 `04 결과 확인`에서 완료된
결과를 선택합니다. 비교할 때는 대표 결과 하나를, 일괄 처리할 때는 `결과 모두 선택`이나
Ctrl/Shift로 여러 결과를 선택하세요. 파란색으로 선택한 결과 행이 대상이며 입력
영상의 사용 체크와는 별개입니다.

1. 설정 비교: 결과 하나에서 `비교하고 조합 만들기`를 엽니다. 보정 전 좌표와
   최대 3개의 중앙값 범위(예: 3, 5, 7프레임)를 총 4개 화면에서 동기 재생합니다.
   미리보기에는 저장된 후처리 파일이 필요하지 않습니다.
2. 설정과 처리: `전체 신체점 동일`에서 공통 중앙값 범위를 정하거나 `신체점별 설정`에서
   저장한 조합을 고릅니다. `선택 결과 보정` 또는 선택 개수가 표시된 버튼을 누릅니다.
   트래킹 결과의 우클릭 메뉴에서도 같은 기능을 제공합니다.
3. 확인과 교정: `저장본 보기`에서 결과를 고르고 `저장본 비교 열기` 또는 `후처리본으로 교정`을
   사용합니다. 저장한 수동 교정을 학습에 추가하려면 `새 수정 프레임 반영`을 사용하세요.
   행동 분석 입력은 영상 트래킹에서 따로 지정합니다.

### 조합과 비교

조합에서는 신체점마다 `보정 전 유지` 또는 3~31프레임의 홀수 중앙값 범위를
선택합니다. 점의 표시, 숨기기 체크와는 별개입니다. 조합 편집기는 보정 전 좌표,
`설정 미리보기`와 최대 2개 비교 범위를 표시합니다. 이름을 입력하고 `이 설정 사용`을
누르면 프로젝트 공용 조합 JSON을 저장하고 작업대의 2단계에서 선택합니다.
아직 후처리 H5/CSV 파일을 만들지는 않습니다. 취소하면 이전 선택을 유지하고,
미사용 변경을 버리기 전에 확인합니다.

저장한 조합은 두 작업대에서 사용할 수 있습니다. 모델 평가에서 시험한 뒤 여러
트래킹 결과에 적용하세요. 각 필터는 보정 전 좌표를 사용하므로 공통 필터를 먼저
실행할 필요가 없습니다. 같은 프레임 범위도 영상 FPS에 따라 실제 시간 길이는
달라집니다. 신체점 이름 구성이 다른 결과에는 같은 조합을 사용할 수 없습니다.
신체점 구성이 다르거나 영상이 선택한 범위보다 짧아 전환할 수 없으면 미리보기에 이유가 표시됩니다.

비교 화면은 재생, 프레임 이동, 휠 확대와 가운데 버튼 이동이 동기화됩니다.
왼쪽 목록에서 다른 결과를 선택하면 첫 프레임에서 일시정지합니다. 결과 표의
우클릭 메뉴에도 `나란히 비교 열기`가 있습니다. 저장본 비교의 `비교할 필터`에서
표시할 결과를 고르며 후처리본이 없는 영상에는 보정 전 좌표만 표시합니다.
같은 영상과 보정 전 좌표에서 생성한 결과를 비교하고, 직접 선택한 실행이 없으면
각 범위의 최신 결과를 사용합니다. 저장본 비교는 검토용이며 처리나 분석 설정을 바꾸지 않습니다.

후처리 실행마다 프로젝트의 `.hagisilta/pose-filter-tests`에 별도의 H5, CSV와
비교 이력을 저장합니다. 원본 추론, 수동 교정과 학습 라벨은 보존합니다.
조합, 후처리 좌표나 수동 교정을 저장하는 것만으로 행동 분석 입력을 지정하지는
않습니다. 처리가 실패하거나 중단되어도 완성된 결과는 남으며 저장 실패는 오류로
알립니다. 미완료 ROI를 다시 처리한 뒤 완성된 결과를 선택해 분석 입력을 지정하세요.

### 행동 분석에 사용할 좌표 지정

영상 트래킹의 `선택한 N개를 행동 분석에 사용`으로 ROI별 다음 NORT, Y-maze 또는
Water maze 분석 입력을 지정합니다. 저장본은 2단계에서 고른 후처리 방식과 조합에
맞아야 합니다. ROI 하나에서는 직접 고른 일치 저장본을 우선 사용하고, 없으면
최신 일치 저장본을 사용합니다. 일괄 지정에서는 ROI별 최신 일치 저장본을 사용합니다.
원본 추론 좌표로 돌아가려면 `보정 전 사용`을 선택하세요.

지정 전에 모든 입력을 확인합니다. 파일 누락이나 손상, 중복 ROI, 한 ROI의 여러
모델 결과 선택은 지정을 막습니다. 지정한 원본 영상이나 좌표 파일이 바뀌거나
손상되면 입력을 다시 지정해야 합니다. 다른 좌표로 임의 대체하지 않고 재지정을
요청합니다. 파일 출처는 영상 셀의 툴팁에서 확인할 수 있습니다.

입력을 지정한 뒤 분석을 다시 실행해야 결과가 계산됩니다. 지정 과정에서 기존
분석 출력, 모델 평가 점수, 수동 교정과 학습 라벨은 보존합니다. 새 결과에는 사용한
좌표 파일과 후처리 조합을 기록합니다.

## 분석 판정 신체점

NORT, Y-maze, Water maze와 일반 구역 분석에서는 분석 대상으로 체크한 좌표
결과의 신체점 이름을 제공합니다. 결과마다 구성이 다르면 정확한 이름이 공통인
점만 선택할 수 있습니다. 파란 편집 행과 분석 대상 체크는 별개입니다.
툴팁에서 출처, 불일치와 아직 좌표가 없는 Arena를 확인합니다.

아직 좌표가 없으면 선택한 트래킹 모델의 신체점 목록을 표시합니다.
이름의 대소문자와 순서를 보존하며, 같은 모델의 목록을 새로 고쳐도 체크 상태나
전체 해제 상태를 유지합니다. 명시적으로 선택한 분석 입력이 손상되면 사용 전에 확인해야 합니다.

Water maze에서 선택한 신체점이 좌표 파일에 없으면 해당 파일과 누락 이름을
알리고 분석을 중단합니다. 남은 점만으로 중심을 계산하거나 `body_center`와
`bodycenter` 같은 다른 이름을 같은 점으로 취급하지 않습니다.

## Y-maze 분석 구간

`Y-maze → Arena 구성 → 분석 구간 편집`에서 ROI 하나의 시작과 종료를 지정합니다.
시간은 `분:초.밀리초`로 입력하거나 `S/F`로 현재 장면을 시작/종료로 정합니다.
직접 입력한 시간을 확정하면 그 장면으로 이동합니다. 시작 10분 뒤를 찾으려면
`기준 시각 + 시간`에서 `분석 시작 기준`을 선택하고 `10:00.000`을 입력하세요.
`위치 보기`는 구간 변경 없이 이동하고 `종료로 지정`은 종료 시각도 바꿉니다.

왼쪽 목록에는 같은 영상의 ROI와 썸네일, 구간이 표시됩니다. 행을 누르면 같은
재생 시각에서 ROI를 전환합니다. 체크는 구간을 복사할 대상을 고르는 기능이며,
현재 파란 행이나 메인 화면의 분석 대상 체크와 별개입니다.
`체크한 N개 ROI에 이 구간 적용`으로 선택한 초안에 복사한 뒤 각각 조정하세요.

`Ctrl+S`는 수정한 모든 ROI를 저장하고 `저장하고 닫기`는 저장 후 창도 닫습니다.
여러 ROI를 저장하면 기존 구간과 새 구간을 확인합니다. 체크를 해제해도 수정한
초안은 저장 대상이며, 취소할 때는 미저장 변경을 버릴지 확인합니다.
저장한 구간은 다음 분석 실행부터 적용하고 원본 영상, 좌표와 기존 결과는 유지합니다.

## ROI 검수와 실험 화면 표시

### ROI 일괄 검수

기준 카드를 고른 뒤 `모두 선택`, `검색 결과 선택`, `ROI 없는 영상 선택` 또는
`모두 해제`를 사용합니다. 기준 카드는 대상에서 제외합니다.
`기존 ROI도 덮어쓰기`를 선택하지 않으면 기존 설정을 보존합니다.
Water maze 수조와 플랫폼 전체 검수도 같은 선택 방식을 사용하며 같은 Arena의
여러 Trial을 한 카드로 묶습니다. 영상 카드를 열어 편집한 뒤 검수 목록으로 돌아옵니다.

### Water maze 표시

개체별 구간 등록 창의 영상 위 `ROI 표시`에서 저장된 수조, 플랫폼, 사분면과 벽면
구역을 각각 켜거나 끕니다. ROI가 없거나 손상되었거나 다른 영상 또는 다른 크기의
설정이면 확인 안내가 나옵니다.

궤적 및 히트맵 편집기의 `벽면 구역`은 분석에 사용한 벽면 선호 구역의 안쪽 경계를
점선으로 표시합니다. 표시 여부, 색과 두께는 미리보기와 저장 이미지에 함께
적용합니다. 저장된 기준이 없으면 안내가 표시됩니다. 이러한 화면 표시는 ROI 도형,
분석 구간과 수치 결과를 바꾸지 않습니다.

### Y-maze 경계

트래킹 ROI(T), Maze 외곽(H), 구역 채움(J) 표시를 각각 조절할 수 있습니다.
Center는 세 Arm 입구를 모두 가로질러야 합니다. Center와 Arm은 정렬된 경계를
공유하며 편집한 내용은 저장할 때 ROI 파일에 반영됩니다. 표시를 켜거나 끄는 것은
좌표를 바꾸지 않습니다.

## 휴대용 프로젝트 내보내기와 가져오기

영상 포함 여부와 트래킹 및 분석 결과 포함 여부를 각각 선택합니다.
프로젝트 폴더 밖의 등록 영상도 포함할 수 있으며 ROI 프로필과 프로젝트별 입력
설정도 함께 내보냅니다. 추론과 교정 작업이 끝난 뒤 내보내세요.
포함할 영상이 없으면 해당 파일을 알리고 새 ZIP을 만들지 않습니다.

가져올 때 영상, ROI, 교정 이력과 분석 입력 경로를 새 위치에 맞춥니다.
저장된 교정 좌표, 출처와 시간 문맥 설정을 유지합니다. 서로 다른 폴더에 있는
동일한 이름의 파일은 따로 보존하고 다른 프로젝트의 전역 설정은 가져오지 않습니다.

영상을 제외했다면 같은 PC에서는 기존 경로를 사용할 수 있습니다. 다른 PC에서는
대시보드의 `경로 복구`로 원본 또는 ROI 영상 폴더를 연결한 뒤 ROI 편집과 영상
확인을 사용하세요. 같은 이름의 후보가 여러 개이면 확인이 필요합니다.
영상을 ZIP에 담아 옮기려면 영상 포함을 선택해 다시 내보내세요.

## 프로젝트 데이터

프로젝트는 프로그램과 별도로 Windows의 문서 위치 아래
`문서\HAGISILTA-work`에 저장됩니다. 프로그램 배포판에는 실험 영상, ROI, 라벨,
학습 모델, 추론 결과와 개인 프로젝트를 포함하지 않습니다.

기존 NORT 프로젝트는 `config.yaml`을 선택하거나 프로젝트 ZIP을 가져와 여세요.
